What it does

Usage at a glance

5-hour and weekly limits for every account, in the tray and a floating overlay.

Chat hub

Every Claude Code session as a real chat. Sessions keep running when the app is closed.

Code mode

File tree, diffs and commits in one place to review before you push.

Project dashboard

Todos, chats, ship state, usage and custom cards for each project.

Phone remote

Pair an Android phone and answer questions or steer chats from anywhere.

Multi-machine

Pair your PC and your Mac and see all your chats in one place.
