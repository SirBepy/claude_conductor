# STT sidecar is not bundled

Read before touching `src-tauri/src/daemon/stt.rs`, `stt-sidecar/` or the installer contents.

## Dictation rewrite (`src-tauri/src/voice/`)

Read before touching `voice/cleanup.rs`, `voice/rewrite.rs`, `voice/vocab_seed.rs` or `composer-voice.ts`'s swap.

- **Flow:** stopping a dictation leaves the raw words in the composer and starts `voice_clean_transcript` without awaiting it; the reply swaps in only if the span is still exactly the raw text and the composer was not cleared meanwhile (`gen`). `Send` waits at most 1.5 s (`settleRewrite`), then goes out raw and cancels the swap. Ctrl+Z within 10 s of a swap restores the raw words (the composer has no text undo of its own, dictation writes `value` directly).
- **Lean spawn, measured 2026-11-23:** a default `claude -p` haiku call took 6.1 and 7.2 s, the lean flag set 2.5 to 3.7 s. `rewrite::lean_args` carries `--tools ""`, `--no-session-persistence`, `--setting-sources ""`, `--strict-mcp-config` with an empty config file and `--system-prompt-file`; they are privacy and injection controls as much as speed ones (without them every dictation loads the user's hooks and MCP servers and is written to a session log). The transcript goes over stdin, never argv. A drift test pins the flags.
- **Output contract:** the reply must sit in `<out></out>` (the LAST `</out>` closes it), length within 0.2x to 2.5x of the input, and every number and path-like token of the input must survive; anything else keeps the raw text. Under 4 words with no list or correction cue the model is not called. 8 s timeout kills the child; one rewrite runs at a time (a phone-reachable RPC must queue, not fan out); input over 6000 chars is refused.
- **Vocabulary:** `voice-vocab.json` has `terms` (the user's own, never touched by code) and `seeded` (project and folder names, rewritten on every daemon start by `vocab_seed`). The sidecar's hotwords take `terms` first then `seeded` up to 300 characters (about 100 tokens: rare words cost 3 to 6 tokens each and faster-whisper truncates the prompt); the rewrite prompt gets both, capped at 150 terms, as quoted data. `voice-corrections.json` pairs are applied by the sidecar in one longest-first alternation pass. People and client names are NOT seeded: they would reach a third-party model, which needs Joe's OK.
- **Not built (judged 2026-11-23, see `docs/voice-mode-plan.md` section 15):** warm process pool, learn-from-edits, Dictionary UI, eval clip saver, fuzzy correction. Revisit by evidence after real use.

- **Decided 2026-08-08 (todo 521): the STT sidecar is NOT bundled into the installer.** `SttSupervisor::sidecar_dir()` (`src-tauri/src/daemon/stt.rs`) only finds `stt-sidecar/server.py` via an env override, a recorded app-data path, or a directory walk-up from the exe/cwd - none of which hit on an installed app with no repo nearby, so dictation only works from a source checkout today. Bundling a prepared `.venv` would add roughly 2-4GB (`faster-whisper` + `ctranslate2` + CUDA wheels) to the installer for one user; not worth it unless dictation needs to be portable to a machine without the repo.
